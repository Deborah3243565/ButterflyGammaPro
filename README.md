一款基于 Windows 显卡底层硬件级色彩查找表（LUT）打造的现代化屏幕调色与暗部细节增强工具，专为现代 Windows 10/11 与电竞玩家设计。不仅是 FPS 竞技游戏（逃离塔科夫 EFT、CS2、瓦罗兰特 Valorant、Apex、无畏契约、CF 等）看清暗处老六的制胜神器，更能广泛应用于各类 3A 单机大作、影视追剧暗部还原、深夜护眼及多屏独立色彩管理。

## ⚡ 核心电竞突破：电竞零掉帧极速架构 (Esports Zero-Lag)

> **“按快捷键切滤镜瞬间单次原子写入显卡硬件，耗时仅 0.002ms，显卡交换链 0 停顿，彻底告别对枪卡顿！”**

针对 FPS 玩家在激烈对枪切滤镜时“每按一次快捷键游戏都掉帧卡顿”的电竞致命痛点，`Butterfly Gamma Pro` 全面重构了底层写入流水线：
1. **显卡底层单次原子写入（Direct Instant LUT Apply）**：废除传统的驱动循环过渡重载中断，在专属最高优先级底层独立线程中 0.002ms 内一次性原子写入硬件 LUT，彻底消除 1% Low 帧率暴跌；
2. **常驻屏幕物理设备上下文缓存池（Zero GDI Overhead）**：彻底消除频繁调用 `CreateDC`/`DeleteDC` 的内核上下文切换开销；
3. **轻量化 OSD 浮窗与 DWM 零颠簸**：彻底剔除 GPU 像素模糊着色器（DropShadowEffect），无缝兼容 Windows 10/11 无边框窗口的 Direct Flip 硬件翻转机制。支持在主界面一键关闭浮窗提示，进入纯硬件静默秒切模式；
4. **电竞模式自由开关**：界面提供【⚡ 电竞零掉帧极速模式】开关，开启时享受极限零延迟切滤镜体验。

## 🖥️ 独家多屏架构：原生多显示器（Multi-Monitor）隔离调色

> **“主屏 240Hz/360Hz 打塔科夫提亮室内暗角，副屏 Discord / OBS / 交互地图保持 100% 原厂真实色彩，互不干扰！”**

传统老旧 Gamma 工具在底层硬编码 `GetDC(0)`，多屏环境下副屏会被迫一同刺眼泛白。`Butterfly Gamma Pro` 从底层重构了多显示器设备隔离：
* 🖥️ **物理显示器精准枚举**：自动探测所有物理屏幕的设备路径（`\\.\DISPLAY1`, `\\.\DISPLAY2`...）、物理型号、原生分辨率与硬件刷新率（如 240Hz/360Hz/540Hz）；
* 🎯 **三重视角自由隔离与同步**：
  1. **【🌐 全部显示器】**：所有屏幕同步提亮，适合联屏与大视野游戏需求；
  2. **【🖥️ 仅主显示器 (竞技游戏专用)】**：只提亮前台游戏主屏，副屏色彩丝毫不受影响；
  3. **【📺 指定物理屏幕】**：直接指定目标显示器独立调色；
* 🔄 **热插拔与托盘动态直切**：提供一键检测刷新，托盘右键菜单同步支持实时切换目标屏幕，即点即切。

## 🌟 核心特性总览 (All-In-One Key Highlights)

* 🛡️ **绝对安全，零封禁风险**：基于 Windows 原生硬件级色彩查找表（`SetDeviceGammaRamp`）接口调节，纯外围显卡输出，**零注入、零内存读取、零 DLL Hook**，完全无视 BattlEye、VAC、EAC、EasyAntiCheat 等任何反作弊检测。
* 👁️ **暗部平衡（Black Equalizer）非线性灰阶算法**：专注非线性提亮 0%~25% 的纯暗部死角细节，同时智能锁定 60%~100% 高光区域，室外场景绝不泛白雪盲、枪口火焰不刺眼。
* 🎨 **RGB 三通道独立调节与偏色矫正**：支持全 RGB 联动微调，或单选红（R）、绿（G）、蓝（B）独立通道细调，轻松校正面板偏黄发沉或突出特定目标。
* 🚀 **内置国内多节点全自动静默热更新**：集成官方 API 与国内高速 CDN 镜像节点加速，启动自动检测；发现新版本一键在软件内多线程下载并原地热替换自重启，再也无需前往网页手动下载替换！
* 🎮 **全屏独占穿透热键**：基于 Win32 底层全局钩子与管理员权限清单，无视游戏独占全屏与 UIPI 阻断，支持 F1~F12 及鼠标侧键（Mouse 4/5）。
* 🔒 **单实例互斥唤醒**：内置全局进程互斥锁，多开自动唤醒前台窗口，彻底防止双进程冲突导致的画面频闪与热键失效。
* ⌨️ **热键占用冲突自检**：实时检测热键状态，若热键被其他软件占用，状态栏第一时间友好高亮告警。
* 🎨 **沉浸式深色电竞托盘菜单**：原生 Win32 + WPF 深度定制深色半透明托盘右键菜单，清爽现代。
* ✏️ **支持键盘精确填数**：右上角数字框（暗部平衡、Gamma、对比度、亮度）支持直接点击输入数值，与滑块双向实时联动。
* 🎯 **支持无限自由增删滤镜**：随时点击【➕ 添加滤镜】，任意命名并绑定快捷键。
* 🔔 **游戏内轻量 OSD 浮窗**：切换时在屏幕中上方弹出半透明卡片提示，鼠标穿透且绝对不抢占游戏焦点。
* 🛡️ **防掉滤镜守护心跳 (Anti-Reset)**：游戏切全屏、换图若重置了硬件色彩，后台自动在 1 秒内无感恢复。
* 🛡️ **异常崩溃还原兜底**：进程退出、异常崩溃时自动触发 GDI 兜底还原，防止屏幕残留过曝色彩。
* ⚙️ **灵活的关闭行为记忆**：点击右上角关闭(✕)、按 Alt+F4 时，严格遵循记住的最小化至托盘或彻底退出选项。

### 1. 🎮 竞技 FPS 与求生夺金（看清暗角老六）
* 《逃离塔科夫 EFT》、《CS2》、《无畏契约》、《Apex 英雄》、《暗区突围 PC》、《PUBG》：室内暗角、商场阴影、楼道老六一览无余，对枪零掉帧。

### 2. 🧟 恐怖求生与动作 / RPG 大作（无消耗物理夜视仪）
* 《生化危机》、《寂静岭》、《心灵杀手 2》、《消逝的光芒》、《黑神话：悟空》、《艾尔登法环》：黑夜野外与暗黑地牢细节清晰可见，走出暗处后按 `F7` 秒切回原厂真实色彩。

* 提升高反差电影夜战镜头灰阶通透度，看清阴影微表情与背景暗光层次。

### 4. 🖥️ 拯救低素质、老化面板（硬件级色彩补偿）
* 修复普通 VA 屏黑位塌陷（Black Crush），补偿老旧背光发沉发暗，白天强光反光下提升画面清晰可读性。

## 📖 独立便携与配置说明 (Portable & Isolated)

本程序支持真正的**全绿色便携模式（Portable）**：
* 程序的配置文件 `config.json` 严格保存在可执行文件所在的同级目录下；
* 将本文件夹拷贝到任意目录运行，仅读写当前文件夹内的 `config.json`，不会对系统其他位置造成任何配置残留。
